# iPAS AI 應用規劃師中級刷題站 v1.4

科目 1、科目 2 共 200 題原創練習，支援練習、限時模擬考、答題信心、即時解析、錯題本、1／3／7 天延遲複習、弱點分析與進度備份。

## v1.4 新功能

- 可安裝到電腦或手機主畫面，像 App 一樣開啟
- 第一次成功連線後，沒有網路也能刷完整題庫
- 深色／淺色模式
- 標準／大／特大三段字體
- 離線狀態提示

所有學習紀錄只存放在目前裝置的瀏覽器，不會上傳到伺服器。

## 更新到 GitHub Pages

1. 解壓縮 ZIP。
2. 將解壓縮後的全部檔案上傳到 GitHub Repository 的最外層；請勿只上傳 `index.html`。
3. 若 GitHub 詢問是否覆蓋舊檔，請保留所有新版檔案。
4. 進入 **Settings → Pages**。
5. 在 **Build and deployment** 將 Source 改為 **Deploy from a branch**。
6. Branch 選 **main**，資料夾選 **/(root)**，再按 **Save**。
7. 等待約 1～3 分鐘，再重新整理 GitHub Pages 網址。

這一版必須包含 `manifest.webmanifest`、`sw.js`、`icon-192.png` 與 `icon-512.png`，安裝及離線功能才會生效。
