# iPAS AI 應用規劃師中級刷題站 v1.4.1

科目 1、科目 2 共 200 題原創練習，支援練習、限時模擬考、答題信心、即時解析、錯題本、1／3／7 天延遲複習、弱點分析、進度備份、離線安裝、深色模式與字體大小調整。

## v1.4.1 修正

- 提高深色模式主要按鈕與科目卡片的文字對比
- 修正「練習本科」按鈕淺底配淺字的問題
- 改善停用按鈕及小標文字的可讀性

## 更新到 GitHub Pages

1. 解壓縮 ZIP。
2. 將解壓縮後的 12 個檔案全部上傳到 GitHub Repository 最外層。
3. 新版檔案請覆蓋舊版同名檔案。
4. Pages 維持 **Deploy from a branch → main → /(root)**。
5. 等待約 1～3 分鐘，再按 `Ctrl＋F5` 重新整理網頁。

如果仍顯示舊色彩，可再關閉網頁後重新開啟一次，讓離線快取更新至 v1.4.1。

> 本專案為非官方學習工具，題目皆為原創練習題，不是官方網站或官方題庫。
