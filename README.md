# iPAS AI 應用規劃師中級刷題站 v1.5

科目 1、科目 2 共 200 題原創練習，支援限時模擬考、延遲複習、逐項解析、個人筆記、重點卡片、離線安裝、深色模式與字體大小調整。

## v1.5 新功能

- 答題後逐一說明四個選項為什麼正確或不適合
- 每題可寫最多 600 字個人筆記，輸入後自動儲存
- 題目可收藏或移出重點卡片
- 首頁可單獨練習已收藏的重點卡片
- 筆記及重點卡會跟著學習進度一起匯出／匯入

## 更新到 GitHub Pages

1. 解壓縮 ZIP。
2. 將解壓縮後的 12 個檔案全部上傳到 GitHub Repository 最外層。
3. 新版檔案請覆蓋舊版同名檔案。
4. Pages 維持 **Deploy from a branch → main → /(root)**。
5. 等待約 1～3 分鐘，再按 `Ctrl＋F5` 重新整理網頁。

如果仍顯示舊版，可關閉網頁後重新開啟一次，讓離線快取更新至 v1.5。

> 本專案為非官方學習工具，題目皆為原創練習題，不是官方網站或官方題庫。
