# iPAS AI 應用規劃師中級刷題站 v1.6

一個可直接部署到 GitHub Pages 的純前端刷題網站，範圍包含：

- 科目 1：人工智慧技術應用與規劃
- 科目 2：大數據處理分析與應用

目前內建 200 題原創練習題，科目 1、科目 2 各 100 題，支援自訂刷題、20／50 題限時模擬、錯題管理、信心程度、即時解析、1／3／7 天延遲複習、章節弱點分析、進度備份與手機版介面。所有學習紀錄只存放在使用者瀏覽器的 `localStorage`，不會上傳到伺服器。

## v1.6 新功能

- 可自訂科目、章節、難度與 5／10／20／30／50 題練習
- 新增 50 題、60 分鐘「完整模擬」；此為本站練習設定，非官方題數或時間規格
- 模擬考以 70 分作為本站練習線，並分列科目 1、科目 2 成績
- 首頁保存最近 6 回模擬考趨勢與各科分數
- 新增錯題管理中心，可依科目／章節篩選、集中重練、加入重點卡或標記已掌握
- 模擬考紀錄、錯題、筆記與重點卡都會包含在進度匯出檔

## v1.5 新功能

- 答題後逐一說明四個選項為什麼正確或不適合
- 每題可撰寫最多 600 字個人筆記，輸入後自動儲存
- 題目可收藏成重點卡片，並從首頁單獨複習
- 筆記與重點卡片會跟著學習進度一起匯出／匯入

## 本機開啟

這是純靜態網站，可直接開啟 `dist/index.html`。若瀏覽器限制本機檔案，可在專案根目錄執行：

```bash
python -m http.server 8000 --directory dist
```

再開啟 `http://localhost:8000`。

## 部署到 GitHub Pages

1. 在 GitHub 建立一個新的空白 Repository。
2. 將本專案推送到 Repository。
3. 進入 **Settings → Pages**。
4. 若上傳的是本專案原始結構，可使用 GitHub Actions 發布 `dist` 目錄；若使用提供的 GitHub ZIP，請將 ZIP 內檔案全部上傳到 `main` 根目錄，並將 Pages 設為從 `main / (root)` 發布。

## 新增題目

開啟 `dist/questions.js`，依照既有格式加入題目：

```js
{
  id: "s1-033",
  subject: 1,
  topic: "主題名稱",
  difficulty: "基礎",
  question: "題目文字",
  options: ["選項 A", "選項 B", "選項 C", "選項 D"],
  answer: 0,
  explanation: "答案解析"
}
```

`answer` 使用從 0 開始的索引：A = 0、B = 1、C = 2、D = 3。
